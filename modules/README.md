# Modules
Put module folders here. Please don't upload them to GitHub.
## README file
All experiment modules must contain a README file, either as README.txt or README.md, that describe the module and state how long it should be active. If a file is missing **it will be assumed that the module can be archived**.

Because the README file might be scanned using a script, it must contain the following exact text:

Experiment name: {name}

Web URL: {url}

Responsible scientist(s): {names **and** email addresses}

Date it closes to data collection {date}

Replace the {items in braces} with the correct information.

Also add anything else it might be useful for someone to know.
