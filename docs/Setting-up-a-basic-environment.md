# Setting up a basic environment

## Vagrant (recommended)

There are plenty of ways to set up a basic development environment and anything that works for you will be fine. You could install the applications within a virtual machine and run it as required. [Vagrant can be used to set up such a system](using-vagrant-to-provide-a-web-server.md) with the web files stored in the local file system making them easier to back up or synchronise with cloud services.

## Nginx and PHP

It is also possible to [use local installations of Nginx and PHP](using-native-installs-of-nginx-and-php.md) to create a development environment.
